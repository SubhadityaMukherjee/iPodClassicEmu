# AudioToolbox — AudioServices system sounds

`AudioServices` (in the AudioToolbox framework) is the oldest, simplest
audio API on iOS: "play this short sound file, fire-and-forget." It's how
the wheel's tick sounds work.

```swift
var soundID: SystemSoundID = 0
AudioServicesCreateSystemSoundID(url as CFURL, &soundID)  // load .caf once
AudioServicesPlaySystemSound(soundID)                     // play, no callbacks
```

## Why AudioServices and not AVAudioPlayer for ticks?

This is the deliberate choice worth understanding:

| | AudioServices | AVAudioPlayer |
|---|---|---|
| Latency | lowest — built for UI feedback | higher (session negotiation) |
| Audio session | **doesn't touch it** | owns/configures it |
| Length | short sounds only (≤30s) | anything |
| Control | fire-and-forget | volume/loop/position |

The wheel fires dozens of ticks per second during a spin. An
`AVAudioPlayer` per tick would trample the app's carefully configured
`AVAudioSession` (the category MusicKit playback depends on) and add
latency. AudioServices plays above/orthogonal to the session — which is
also why a rule in `TickSounds` is **never** to reconfigure the audio
session there. One sound, preloaded `SystemSoundID`s, zero session
interaction.

## The sounds

`Resources/Sounds/*.caf` — `Tick.caf`, `TickSoft.caf`, `RubberBand.caf`,
`AlarmBeep.caf`, regenerated by script (python `wave` + `afconvert` to
`.caf` LEI16 44.1k mono — the one format AudioServices loves). IDs are
created once at load and reused; re-creating per tick leaks.

## Volume behavior & haptic pairing

`AudioServicesPlaySystemSound` plays at a fixed level through the system
mix (respects the silent switch); there's no per-call volume API — the
soft/regular distinction is two different files. Each wheel detent can
produce a tick sound + a haptic transient together;
`WheelFeedback` throttles the pair as one unit (see
[corehaptics.md](corehaptics.md)).

## Gotchas

- No completion callback in practice (there is one, but it's unreliable) —
  never build logic on "sound finished".
- `.caf` (Core Audio Format) is the zero-friction container; mp3 in this
  API is asking for pain.
- These sounds respect the ringer/silent switch — by design here (a silent
  phone stays silent), but don't expect ticks in silent mode.
